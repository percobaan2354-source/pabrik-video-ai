Pabrik Video AI

Aplikasi internal untuk otomatisasi pembuatan dan pengunggahan video edukasi singkat ke YouTube menggunakan YouTube Data API v3.

Kebijakan Privasi (Privacy Policy)

Aplikasi ini hanya digunakan oleh pemilik akun untuk mengunggah video ke channel YouTube pribadinya sendiri melalui izin resmi youtube.upload.

Kami tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna pihak ketiga mana pun. Token otorisasi disimpan secara terenkripsi di GitHub Secrets milik pemilik.
